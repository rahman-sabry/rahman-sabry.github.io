About

Contact me →

I'm a backend developer in the insurance technology space, where I build and maintain web applications for enterprise clients using Python, Django, Django REST Framework, and React. Over three and a half years, my scope has expanded well beyond backend code — I now regularly work across frontend SPAs, containerised deployments, cloud infrastructure, and AI-powered features.

Before switching to software, I spent nearly three years at PERKESO as an investment analyst. A data pipeline I built in Excel VBA and PowerQuery M — which cut analyst processing time by over 50% — made it clear that building tools was what I actually wanted to do. I self-studied Python and transitioned into software development.

My early work was focused on Django features and debugging production issues. Over time I took on increasingly complex ownership — delivering policy workflow features as the sole developer, redesigning transaction and refund flows without disrupting live business operations, and resolving server-side database issues that could not be reproduced locally.

More recently I've taken ownership of larger full-stack product work: rebuilding an insurance rating platform from a Django/Tailwind interface into a React SPA backed by Django APIs and WebSocket agent features, helping launch a regulated insurance product in a new market, and authoring internal AI-assisted tooling for ticket-to-code and deployment-audit workflows. I'm AWS Certified and actively deepening my cloud architecture knowledge.
